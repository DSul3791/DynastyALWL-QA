DynastyALWL-QA

## For testers: report a problem or an idea

- **In the game:** Esc > Settings > **Report a problem**. Type what happened and press Save: the game writes a small report file (your note, the build number and the end of the game's log) and opens its folder. Send that file to Dave any way you like. The server pick page has the same button, for when you cannot get into a world.
- **With a GitHub account:** [open a bug or an idea](https://github.com/DSul3791/DynastyALWL-QA/issues/new/choose). The button in the game fills in your build number for you; drag the report file into the form.

## For testers: report a problem or an idea

Testers report problems and ideas here on GitHub, with these forms. There is no reporting from inside the game.

- [Open a bug or an idea](https://github.com/DSul3791/DynastyALWL-QA/issues/new/choose). You need a free GitHub account.
- Give the build number from the game's title page, say what happened, and drag in your game log (the bug form says where it is).
